# Value Creation Model

<div align="center">
  <img src="../../04-brand/assets/logo/mehkam-symbol.svg" alt="Mehkam Logo" width="150" />
</div>

## Overview

This document defines the official value creation model of Mehkam Holding.

Mehkam creates long-term value by building businesses and systems rather than isolated products.

The holding company provides shared capabilities, strategic leadership, organizational support, engineering standards, operational systems, and reusable infrastructure that enable portfolio companies to execute faster and scale more efficiently.

The model is designed to create a compounding effect across the Mehkam ecosystem.

As Mehkam develops new capabilities, those capabilities become reusable organizational assets that can benefit existing and future businesses.

# Purpose

The purpose of the Mehkam Value Creation Model is to define how Mehkam Holding creates, delivers, and compounds value across its portfolio.

This model exists to:

- Establish Mehkam's value creation philosophy.
- Define the primary value creation capabilities of the holding.
- Reduce duplicated effort across portfolio companies.
- Accelerate business and product development.
- Improve engineering and operational quality.
- Enable scalable organizational growth.
- Create reusable capabilities across the Mehkam ecosystem.
- Strengthen the long-term value of portfolio companies.

# 1. Value Creation Philosophy

Mehkam Holding creates value by building systems rather than isolated products.

Instead of requiring every portfolio company to independently develop every organizational capability, Mehkam provides a shared foundation that allows businesses to focus their resources on their core products, customers, and markets.

The holding-level approach is based on three fundamental ideas:

- Build reusable capabilities.
- Transfer those capabilities across businesses.
- Continuously improve the shared foundation.

This creates a compounding value effect in which the growth of one capability can improve the execution capacity of multiple businesses.

# 2. Core Value Creation Pillars

Mehkam creates value through a set of core organizational capabilities.

## 2.1 Capital

Mehkam provides financial resources and strategic investment to support sustainable business development.

Capital allocation is intended to:

- Fund business creation.
- Support product development.
- Enable strategic expansion.
- Develop organizational capabilities.
- Support long-term portfolio growth.

Capital should be allocated according to strategic priorities and expected long-term value creation.

## 2.2 Strategy

Mehkam provides strategic direction and long-term organizational alignment.

Strategic support includes:

- Long-term vision.
- Business direction.
- Market positioning.
- Strategic priorities.
- Portfolio-level planning.
- Organizational development.

The objective is to provide direction without unnecessarily controlling Business Unit execution.

## 2.3 Engineering

Mehkam develops engineering excellence across its ecosystem.

Engineering value creation may include:

- Shared architecture principles.
- Technical standards.
- Development practices.
- Engineering processes.
- Reusable platforms.
- Security standards.
- Infrastructure capabilities.
- Engineering knowledge.

Engineering capabilities should reduce technical duplication while preserving Business Unit autonomy.

## 2.4 Operations

Mehkam develops organizational and operational systems that improve execution quality.

Operational value creation includes:

- Governance frameworks.
- Operating principles.
- Documentation standards.
- Organizational processes.
- Management systems.
- Performance practices.
- Internal operational knowledge.

The objective is to create scalable systems that can support multiple businesses without creating unnecessary bureaucracy.

## 2.5 Brand

Mehkam develops brand capabilities that strengthen the identity and market presence of portfolio companies.

Brand capabilities may include:

- Brand identity.
- Design systems.
- Marketing principles.
- Communication standards.
- Brand strategy.
- Organizational positioning.

Each portfolio company may maintain its own market identity while benefiting from Mehkam's broader brand and strategic capabilities.

## 2.6 Shared Infrastructure

Mehkam may provide common infrastructure and technology services that can be reused across portfolio companies.

Examples include:

- Cloud infrastructure.
- Security practices.
- DevOps tooling.
- Automation platforms.
- Internal technology services.
- Monitoring systems.
- Development infrastructure.
- Shared operational tooling.

Shared infrastructure should create leverage while avoiding unnecessary technical dependency between independent businesses.

# 3. Value Delivery Model

Mehkam delivers value to portfolio companies through shared capabilities and strategic support.

The value delivery model includes:

- Building shared organizational capabilities.
- Standardizing engineering and operational excellence.
- Reducing duplicated effort across companies.
- Accelerating product development.
- Improving execution quality.
- Supporting strategic decision-making.
- Providing reusable technology and infrastructure.
- Developing organizational knowledge.
- Supporting sustainable long-term growth.

The general value flow is:

```text
Mehkam Capability Development
        ↓
Shared Organizational Asset
        ↓
Adoption by Portfolio Companies
        ↓
Improved Business Execution
        ↓
Business Growth
        ↓
Increased Portfolio Value
        ↓
Further Capability Development
```

This creates a continuous feedback loop between holding-level capability development and portfolio-level business growth.

# 4. Expected Outcomes

The Value Creation Model enables portfolio companies to:

- Focus on their core products and markets.
- Launch faster.
- Scale more efficiently.
- Maintain high engineering quality.
- Reduce operational overhead.
- Access proven organizational systems.
- Reuse established technology capabilities.
- Reduce duplicated investment.
- Improve decision-making.
- Build sustainable operating models.

The objective is not to centralize every function, but to provide leverage where shared capabilities create meaningful economic or strategic value.

# 5. Strategic Impact

The shared value creation model strengthens individual portfolio companies while continuously improving the overall Mehkam ecosystem.

As Mehkam grows, every successful capability, process, system, and organizational practice can become a reusable asset.

This produces a compounding effect:

```text
Business A
    ↓
Capability Development
    ↓
Mehkam Shared Asset
    ↓
Business B + Business C + Future Businesses
    ↓
Improved Ecosystem Capability
    ↓
Higher Portfolio Value
```

The long-term objective is to transform organizational knowledge and capabilities into reusable strategic assets.

# 6. Value Creation Principles

## 6.1 Build Once, Reuse Where Valuable

Capabilities that can provide meaningful value across multiple businesses should be designed for reuse.

## 6.2 Business Independence

Shared capabilities must not eliminate the operational independence of portfolio companies.

## 6.3 Value Before Centralization

A capability should be centralized or shared only when doing so creates measurable strategic, operational, or economic value.

## 6.4 Capability Compounding

Every successful capability developed within the Mehkam ecosystem should have the potential to improve future business creation and execution.

## 6.5 Long-Term Value Over Short-Term Efficiency

Decisions should prioritize sustainable portfolio value rather than optimizing isolated short-term metrics.

## 6.6 Continuous Improvement

Shared capabilities should evolve through feedback from the businesses using them.

# Scope

This model applies to:

- Mehkam Holding.
- Current portfolio companies.
- Future subsidiaries.
- Businesses created by Mehkam.
- Shared organizational capabilities.
- Shared technology and infrastructure.
- Holding-level strategic support functions.

It provides a framework for determining how Mehkam creates value while preserving the operational independence of its businesses.

# Governance

The Value Creation Model is an official strategic framework of Mehkam Holding.

Shared capabilities should be developed and maintained when they provide meaningful value to the ecosystem.

The model should be reviewed when:

- Mehkam's operating model changes.
- The portfolio significantly expands.
- New shared capabilities are introduced.
- Organizational responsibilities change.
- Major infrastructure strategies change.
- Scheduled strategic reviews take place.

Any material modification to this model must follow Mehkam's governance and documentation review process.

# Ownership

**Owner:** Mehkam Holding

**Responsible Team:** Mehkam Strategy Team

The owner is responsible for maintaining the strategic integrity of the value creation model and ensuring that holding-level capabilities remain aligned with portfolio needs.

# Final Statement

The Mehkam Value Creation Model represents one of the core strategic foundations of Mehkam Holding.

By developing shared capabilities, providing strategic leadership, strengthening engineering and operational excellence, and creating reusable organizational assets, Mehkam enables its portfolio companies to execute more effectively and grow sustainably.

The ultimate objective is to create a compounding ecosystem in which every new capability strengthens existing businesses, improves future business creation, and increases the long-term value of Mehkam Holding.
