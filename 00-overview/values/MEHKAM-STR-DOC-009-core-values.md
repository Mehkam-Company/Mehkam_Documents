# Mehkam Core Values

## Overview

This document defines the fundamental values that guide Mehkam Holding's culture, leadership, decision-making, and long-term organizational behavior.

These values establish a shared foundation for every company, team, product, and decision across the Mehkam ecosystem.

They are intended to remain stable as the organization grows and should influence how Mehkam builds businesses, develops people, allocates capital, and executes strategy.

---

# 1. Purpose

The purpose of Mehkam Core Values is to:

- Create a unified organizational culture.
- Guide strategic and operational decision-making.
- Define leadership expectations.
- Support consistent behavior across all subsidiary companies.
- Establish a long-term organizational identity.

---

# 2. Core Values

Mehkam Holding is built upon the following core values:

| Value                  | Purpose                                                                     |
| ---------------------- | --------------------------------------------------------------------------- |
| Ownership              | Take full responsibility for outcomes and commitments.                      |
| Long-term Thinking     | Prioritize sustainable growth over short-term gains.                        |
| Excellence             | Pursue high standards in every decision and execution.                      |
| Integrity              | Act with honesty, transparency, and accountability.                         |
| Systems Thinking       | Solve problems by understanding entire systems rather than isolated events. |
| Continuous Improvement | Continuously improve people, processes, and products.                       |
| Capital Responsibility | Manage financial, human, and operational resources responsibly.             |
| Builder Mindset        | Focus on creating, growing, and strengthening Mehkam's own companies.       |

---

# 3. Organizational Commitment

Every member of Mehkam Holding is expected to understand, apply, and protect these values.

These principles are not temporary initiatives or management slogans. They represent the long-term behavioral foundation of the organization.

All future policies, leadership practices, engineering standards, hiring decisions, and operational frameworks should remain aligned with these values.
