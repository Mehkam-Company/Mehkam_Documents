# Brand Documentation Hierarchy and Numbering Standard

## Overview

This document defines the official hierarchy, folder organisation, and numbering system for Mehkam Brand Documentation.

The purpose of this standard is to ensure all brand-related documents across Mehkam Holding follow a scalable and consistent structure.

This standard applies to:

- Mehkam Holding
- Existing subsidiary brands
- Future portfolio companies

# 1. Brand Documentation Repository Structure

All brand documentation must follow the official structure:

```text
04-brand/

├── 00-overview
│
├── 01-strategy
│
├── 02-identity
│
├── 03-guidelines
│
├── 04-communication
│
├── 05-assets
│
├── 06-governance
│
└── 07-documentation
```

# 2. Category Hierarchy

## 00-overview

Purpose:

Defines the fundamental brand foundation.

Contains:

- Brand overview
- Brand architecture
- Brand ecosystem

## 01-strategy

Purpose:

Defines strategic brand direction.

Contains:

- Brand purpose
- Vision
- Mission
- Positioning
- Values
- Audience
- Market research

## 02-identity

Purpose:

Defines visual identity systems.

Contains:

- Logo system
- Colour system
- Typography
- Visual language
- Design elements

## 03-guidelines

Purpose:

Defines rules for applying the brand.

Contains:

- Logo usage
- Colour usage
- Typography rules
- Brand application rules

## 04-communication

Purpose:

Defines brand communication standards.

Contains:

- Voice and tone
- Messaging framework
- Content guidelines

## 05-assets

Purpose:

Stores official brand resources.

Contains:

- Logos
- Icons
- Templates
- Marketing assets
- Media resources

## 06-governance

Purpose:

Defines brand ownership and control.

Contains:

- Approval process
- Ownership rules
- Change management

## 07-documentation

Purpose:

Stores documentation standards and indexes.

Contains:

- Documentation categories
- Documentation hierarchy
- Documentation index
- Documentation roadmap

# 3. Brand Document Naming Convention

All Brand Documentation files must follow this naming format:

```text
Mehkam-BRAND-DOC-[NUMBER]-[DOCUMENT-NAME].md
```

Example:

```text
Mehkam-BRAND-DOC-001-brand-documentation-categories.md

Mehkam-BRAND-DOC-002-brand-document-hierarchy.md
```

# 4. Document Numbering System

Brand documents use sequential numbering.

Format:

```text
Mehkam-BRAND-DOC-XXX
```

Rules:

- Numbering must be unique.
- Existing document IDs must never be reused.
- New documents receive the next available number.

Example:

```text
001
002
003
004
```

# 5. Folder and Document Relationship

Each document belongs to one primary category.

Example:

```text
04-brand

├── 01-strategy
│   └── Mehkam-BRAND-STR-001-brand-positioning.md
│
├── 02-identity
│   └── Mehkam-BRAND-ID-001-logo-guidelines.md
│
├── 03-guidelines
│   └── Mehkam-BRAND-GUIDE-001-brand-usage-rules.md
```

# 7. Version Management

Every brand document must include version information.

Version format:

```text
MAJOR.MINOR.PATCH
```

Example:

```text
1.0.0
```

Version changes:

## Major Version

Used for significant structural changes.

Example:

```text
1.0.0 → 2.0.0
```

## Minor Version

Used for adding new content.

Example:

```text
1.0.0 → 1.1.0
```

## Patch Version

Used for corrections.

Example:

```text
1.0.0 → 1.0.1
```

# 8. Brand Documentation Rules

## Rule 1

Every brand document must belong to a defined category.

## Rule 2

Documents must follow official naming conventions.

## Rule 3

Document IDs must remain permanent.

## Rule 4

New categories require approval from Brand Governance.

## Rule 5

Brand documentation must remain compatible with future Mehkam companies.

# 9. Future Sub-brand Structure

Each Mehkam company may maintain its own brand documentation using the same structure.

Example:

```text
companies/

├── chasha/
│
│── brand/
│   ├── strategy
│   ├── identity
│   ├── guidelines
│   └── assets
│
└── phrifan/
    ├── strategy
    ├── identity
    ├── guidelines
    └── assets
```

# Final Statement

The Mehkam Brand Documentation Hierarchy and Numbering Standard provides a scalable foundation for managing all brand knowledge across Mehkam Holding.

This structure ensures consistency, discoverability, and long-term maintainability for every current and future Mehkam brand.
