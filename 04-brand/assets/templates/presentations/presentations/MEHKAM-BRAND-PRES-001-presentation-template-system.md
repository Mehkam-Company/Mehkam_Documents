# Mehkam Presentation Template System

---

<div align="center">

  <img src="../../04-brand/assets/logo/mehkam-symbol.svg" alt="Mehkam Logo" width="150" />

</div>

## Overview

This document defines the official presentation template system of Mehkam Holding.

The system establishes the structural and visual foundation for all official Mehkam presentations used for corporate, strategic, investment, and internal communication.

The purpose of this system is to provide a consistent, premium, scalable, and reusable presentation framework across the Mehkam ecosystem.

Final visual template execution is delegated to the design phase.

# 1. Presentation System Identity

| Property | Value |

|---|---|

| Organization | Mehkam Holding |

| Document Type | Presentation Template System |

| Primary Language | English |

| Typography | Peyda |

| Visual Direction | Minimal / Luxury / Corporate |

| Primary Colors | Black and White |

| Primary Logo | Mehkam Symbol |

# 2. Presentation System Scope

The Mehkam Presentation Template System covers:

- Corporate Presentations

- Strategic Presentations

- Investment Presentations

- Internal Presentations

All presentation types must follow the same core visual identity while allowing different content structures.

# 3. Presentation Format

The standard presentation format shall be:

\`\`\`text

16:9 Widescreen

\`\`\`

The final master must be suitable for:

- Desktop Presentation

- Large Display

- Projector

- Digital Distribution

- PDF Export

# 4. Presentation Architecture

The standard presentation structure:

\`\`\`text

Presentation

│

├── Cover

├── Agenda / Overview

├── Section Divider

├── Content Slides

├── Data Slides

├── Chart Slides

├── Diagram Slides

├── Quote / Statement

└── Closing

\`\`\`

Not every presentation must contain every slide type.

# 5. Master Grid System

The Presentation Master shall define:

- Slide margins

- Content grid

- Column structure

- Alignment rules

- Spacing system

- Safe areas

- Text boundaries

- Image boundaries

All reusable layouts must align to the same master grid.

# 6. Typography System

The primary presentation typeface shall be:

\`\`\`text

Peyda

\`\`\`

Typography hierarchy:

\`\`\`text

Presentation Title

Section Title

Slide Title

Subtitle

Body Text

Caption

Metadata

\`\`\`

Typography must maintain:

- Clear hierarchy

- Strong readability

- Consistent scale

- Controlled line length

- Consistent spacing

Typography must remain minimal and professional.

# 7. Spacing System

The presentation system shall use a consistent spacing scale.

Spacing must be applied consistently to:

- Titles

- Text blocks

- Images

- Charts

- Tables

- Diagrams

- Section elements

Layouts must avoid unnecessary visual density.

# 8. Visual Hierarchy

Every slide must have one clearly identifiable primary message.

The hierarchy should prioritize:

\`\`\`text

Primary Message

↓

Supporting Information

↓

Evidence / Data

↓

Metadata

\`\`\`

Slides must avoid excessive text, competing visual elements, and unnecessary decoration.

# 9. Cover Layout

The Cover Master shall support:

- Mehkam Symbol

- Presentation Title

- Subtitle when required

- Date

- Author / Organization when required

The Cover must remain minimal and premium.

# 10. Agenda / Overview Layout

The Agenda Layout may contain:

- Presentation Sections

- Topics

- Sequence

- Supporting metadata

The layout must clearly communicate the presentation structure.

# 11. Section Divider Layout

The Section Divider shall visually separate major presentation sections.

Required characteristics:

- Minimal composition

- Strong section title

- Clear hierarchy

- Consistent relationship with the Cover

No unnecessary decorative elements should be introduced.

# 12. Content Layouts

The Master System shall provide reusable content layouts including:

- Title + Text

- Two Column

- Three Column

- Text + Image

- Image + Text

- Full Width Content

- Highlighted Content

Content layouts must remain flexible while preserving the master grid.

# 13. Data Layouts

Data-oriented slides shall support:

- Key Metrics

- KPI Cards

- Numerical Highlights

- Comparison Data

- Structured Tables

Data must be presented with clear hierarchy and sufficient whitespace.

# 14. Chart Layout

Chart layouts shall support:

- Bar Charts

- Line Charts

- Area Charts

- Comparison Charts

- Other approved analytical visualizations

Charts must prioritize:

- Readability

- Accuracy

- Minimal visual noise

- Clear labeling

- Consistent typography

Charts must follow the Mehkam monochromatic visual system unless an approved business-specific visual requirement exists.

# 15. Diagram Layout

Diagram layouts shall support:

- Processes

- Systems

- Relationships

- Organizational Structures

- Flows

- Architecture Concepts

Diagrams must remain:

- Structured

- Minimal

- Easy to understand

- Consistent with the master grid

# 16. Quote / Statement Layout

The Quote Layout shall support:

- Executive Statements

- Strategic Principles

- Key Messages

- Important Statements

The layout must emphasize the message without unnecessary decoration.

# 17. Closing Layout

The Closing Master shall support:

- Closing Statement

- Call to Action when required

- Mehkam Symbol

- Website

Primary website:

\`\`\`text

mehkam.ir

\`\`\`

The Closing slide must remain visually simple and authoritative.

# 18. Image Usage

Images may be used when they provide meaningful communication value.

Image treatment must follow Mehkam visual principles:

- Professional

- Refined

- Structured

- Premium

- Human-centered when appropriate

Images must not overpower the primary message.

# 19. Table Rules

Tables must follow:

- Consistent alignment

- Clear hierarchy

- Controlled density

- Minimal borders

- Consistent typography

Tables should prioritize readability over decorative styling.

# 20. Header and Footer

The presentation system may include:

- Mehkam Symbol

- Presentation Context

- Slide Number

- mehkam.ir

Header and Footer elements must remain visually subordinate to slide content.

# 21. Slide Numbering

Slide numbering shall be available as a reusable master component.

The numbering system must remain consistent across all presentation types.

# 22. Presentation Types

Designed for:

- Company Introduction

- Corporate Communication

- Organizational Presentations

- External Stakeholder Communication

## 22.2 Strategic Presentation

Designed for:

- Strategy

- Roadmaps

- Strategic Reviews

- Organizational Planning

## 22.3 Investment Presentation

Designed for:

- Investment Discussions

- Portfolio Overview

- Business Opportunities

- Financial / Strategic Communication

## 22.4 Internal Presentation

Designed for:

- Team Meetings

- Internal Reviews

- Training

- Operational Communication

The final design system must provide:

- Figma Master Presentation

- Reusable slide layouts

- Editable components

- Consistent typography

- Consistent spacing

- Reusable data components

- Reusable chart components

- Reusable diagram components

The Designer must preserve:

- Mehkam logo rules

- Typography rules

- Color system

- Minimal corporate aesthetic

- Master grid

The following layouts shall be created during the design phase:

- Agenda / Overview

- Section Divider

- Content

- Two Column

- Image + Text

- Data

- KPI / Metrics

- Table

- Chart

- Diagram

- Quote / Statement

- Closing

These layouts shall be implemented as reusable Figma components and masters.

# 28. Completion Criteria

The Presentation Template System is complete when:

- Presentation format is defined.

- Master grid is defined.

- Typography hierarchy is defined.

- Spacing rules are defined.

- Visual hierarchy is defined.

- Core slide layouts are defined.

- Presentation types are defined.

- Data, chart, and diagram rules are defined.

- Production requirements are defined.

- Asset structure is established.

- Naming convention is established.

- Design execution requirements are documented.
