# Mehkam Corporate Stationery System

## Overview

This document defines the official corporate stationery system of Mehkam Holding.

It establishes the structural, visual, and production standards for formal business communication and corporate documentation.

The system provides a consistent foundation for Mehkam letterheads, continuation pages, envelopes, document headers, and document footers.

Final visual execution and production artwork are intentionally deferred until the Mehkam Visual Identity System is fully finalized.

# 2. Stationery System

The Mehkam Corporate Stationery System consists of:

- Official Letterhead
- Continuation Page
- Corporate Envelope
- Document Header
- Document Footer

All components must maintain a consistent visual relationship with the Mehkam Brand Identity System.

# 3. Letterhead System

## 3.1 Formats

The official Letterhead system shall support:

- A4
- US Letter

## 3.2 Language Variants

Separate templates shall be maintained for:

- Persian / RTL
- English / LTR

## 3.3 Header

The Letterhead header shall contain:

- Mehkam Symbol
- Company Name
- Corporate Address

The header must remain minimal and must not introduce unnecessary decorative elements.

## 3.4 Footer

The Letterhead footer shall contain:

- Corporate Address
- Official Website

Current corporate information:

**Address:** Iran — Yazd

**Website:** mehkam.ir

## 3.5 Page Number

Page numbering is not required for the primary Letterhead template.

# 4. Continuation Page

The Continuation Page is intended for documents that extend beyond the first page.

The Continuation Page shall:

- Maintain the same visual language as the primary Letterhead.
- Use a minimal Footer.
- Avoid repeating the primary Letterhead header.
- Maintain approved typography and spacing rules.

# 5. Envelope System

The Corporate Envelope System shall follow the same visual principles as the Mehkam Letterhead.

## 5.1 Visual Direction

Envelopes shall use:

- White background
- Black branding
- Minimal composition
- Premium corporate appearance

## 5.2 Recipient Area

The envelope shall provide a dedicated blank area for recipient information.

## 5.3 Supported Sizes

Envelope dimensions are currently TBD.

Final supported envelope sizes shall be established during the visual execution phase.

# 6. Header & Footer System

The Mehkam Header and Footer System shall provide reusable structural rules for official corporate documents.

## 6.1 Header

The standard Header may contain:

- Mehkam Symbol
- Company Name
- Corporate Address

## 6.2 Footer

The standard Footer may contain:

- Corporate Address
- Official Website
- Document metadata where required

The Footer must remain visually subordinate to the document content.

# 7. Visual Standards

All stationery assets must follow the approved Mehkam Visual Identity System.

## 7.1 Color

The primary stationery color system is:

- Black
- White

No additional colors may be introduced without approval.

## 7.2 Logo

The primary stationery logo is the Mehkam Symbol.

Logo usage must comply with the approved Logo System and Master Logo Asset Package.

## 7.3 Typography

The primary corporate typeface is:

**Peyda**

Typography hierarchy, font weights, sizes, and spacing shall be defined during the final visual execution phase.

## 7.4 Composition

The stationery system must communicate:

- Minimalism
- Luxury
- Corporate authority
- Professionalism
- Consistency
- Longevity

Unnecessary decorative elements must be avoided.

# 8. Language & Direction

The stationery system must support independent language layouts.

### Persian

- RTL
- Persian typography
- Persian content hierarchy

### English

- LTR
- Latin typography
- English content hierarchy

The Persian and English versions must remain visually equivalent while respecting their respective writing directions.

# 9. Production Standards

Final stationery assets shall be produced in:

## 9.1 Editable Master

- Figma

## 9.2 Production Formats

- PDF
- PNG

## 9.3 Production Variants

Both formats shall support:

- Digital usage
- Print usage

Print-specific technical specifications shall be established during final production preparation.

# 10. Asset Structure

The Corporate Stationery assets shall follow:

```text
    └── documents/

            ├── letterhead/

```

# 11. Asset Naming

Stationery assets shall follow the Mehkam asset naming convention.

Recommended pattern:

```text
mehkam-[asset]-[variant]-[language]-[format]-v[version]
```

Examples:

```text
mehkam-letterhead-primary-fa-a4-v1
mehkam-letterhead-primary-en-a4-v1
mehkam-continuation-fa-a4-v1
mehkam-continuation-en-a4-v1
mehkam-envelope-standard-v1
```

# 12. Design Execution

This document defines the structural and governance requirements of the Corporate Stationery System.

The following assets are specified but not yet visually finalized:

- Letterhead
- Continuation Page
- Envelope
- Header System
- Footer System

Final Figma masters and production exports shall be created during the visual execution phase.

# 13. Completion Criteria

The Corporate Stationery System is considered structurally complete when:

- The stationery components are formally defined.
- Letterhead requirements are documented.
- Continuation Page requirements are documented.
- Envelope requirements are documented.
- Header and Footer requirements are documented.
- Brand and typography requirements are documented.
- Language requirements are documented.
- Production requirements are documented.
- Asset structure is established.
- Naming conventions are established.
- Final visual execution is explicitly deferred to the appropriate design phase.
