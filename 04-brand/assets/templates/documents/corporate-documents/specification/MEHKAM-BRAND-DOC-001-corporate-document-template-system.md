# Mehkam Corporate Document Template System

---

<div align="center">
  <img src="../../04-brand/assets/logo/mehkam-symbol.svg" alt="Mehkam Logo" width="150" />
</div>

## Overview

This document defines the official corporate document template system of Mehkam Holding.

The system establishes the structural and visual foundation for all official Mehkam internal and external documents.

The purpose of this system is to ensure consistency, professionalism, scalability, and brand alignment across all corporate documentation.

Final visual template execution is delegated to the design phase.

# 1. Corporate Document Identity

| Property         | Value                        |
| ---------------- | ---------------------------- |
| Organization     | Mehkam Holding               |
| Document Type    | Corporate Template System    |
| Primary Language | English                      |
| Typography       | Peyda                        |
| Visual Direction | Minimal / Luxury / Corporate |
| Primary Colors   | Black and White              |

# 2. Document System Scope

The Mehkam Corporate Document Template System covers:

- Reports
- Proposals
- Memos
- Meeting Documents
- Internal Documentation
- External Corporate Documents

All document types must follow the same visual identity and structural principles.

# 3. Document Architecture

The standard Mehkam document structure:

\`\`\`text
Document
│
├── Cover Page
├── Document Information
├── Header
├── Main Content
├── Tables / Charts / Diagrams
├── Appendix
└── Footer
\`\`\`

# 4. Cover Page System

The Cover Page shall define the first visual impression of official Mehkam documents.

Required elements:

- Mehkam Symbol
- Document Title
- Document Type
- Version
- Date
- Author / Owner when required

The Cover Page must remain minimal and premium.

# 5. Document Information

Official documents may include metadata:

\`\`\`text
Title
Document ID
Version
Status
Owner
Author
Reviewer
Created Date
Updated Date
\`\`\`

Metadata placement shall follow the approved document layout system.

# 6. Header System

The standard Header may contain:

- Mehkam Symbol
- Company Name
- Document Context

The Header must remain visually minimal and subordinate to the main content.

# 7. Footer System

The standard Footer may contain:

- mehkam.ir
- Page Number
- Confidentiality Information when required

The Footer must not distract from document content.

# 8. Layout System

All Mehkam document templates must define:

- Page margins
- Grid system
- Content width
- Spacing rules
- Alignment rules
- Section hierarchy

The layout must support professional corporate documents.

# 9. Typography System

Typography hierarchy shall use:

Primary Typeface:

\`\`\`text
Peyda
\`\`\`

Hierarchy:

\`\`\`text
Document Title
Section Heading
Subsection Heading
Body Text
Caption
Metadata
\`\`\`

Typography must maintain readability and consistency across all documents.

# 10. Document Types

## 10.1 Reports

Reports should support:

- Executive Summary
- Introduction
- Analysis
- Findings
- Conclusion
- Appendix

## 10.2 Proposals

Proposals should support:

- Cover
- Introduction
- Scope
- Solution
- Timeline
- Terms
- Conclusion

## 10.3 Memos

Memos should support:

- Subject
- Recipient
- Sender
- Date
- Content
- Action Items

## 10.4 Meeting Documents

Meeting documents should support:

- Meeting Information
- Agenda
- Discussion
- Decisions
- Action Items

# 11. Visual Content Rules

Documents may include:

- Tables
- Charts
- Diagrams
- Images

All visual elements must follow Mehkam visual principles:

- Clean
- Structured
- Minimal
- Professional

# 12. Design Requirements

The final design system must provide:

- Figma Master Templates
- Reusable layouts
- Editable components
- Corporate consistency

The designer must preserve:

- Mehkam logo rules
- Typography rules
- Color system
- Minimal corporate aesthetic

# 13. Production Formats

Required outputs:

## Editable

- Figma

## Export

- PDF
- PNG

Future document platforms may include:

- Word templates
- Google Docs templates
