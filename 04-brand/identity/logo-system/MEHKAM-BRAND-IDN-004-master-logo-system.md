# Master Logo System

---

<div align="center">
  <img src="../../assets/logo/png/mehkam-symbol-white-2048w.png" alt="Mehkam Logo" width="150" />
</div>

## Overview

This document defines the authoritative Master Logo System of Mehkam Holding.

It establishes the structure, variants, responsive behavior, color treatment, clear-space principles, minimum-size requirements, and usage rules for the Mehkam logo system.

The system is designed to preserve:

- Recognition
- Authority
- Simplicity
- Consistency
- Scalability
- Visual integrity

The Mehkam Symbol is the primary visual identifier of the brand.

---

# 1. Logo Philosophy

The Mehkam logo system is built around a distinctive Symbol derived from the combination of the Persian letterforms:

> **م + ه**

The Symbol is designed to function as an independent brand identifier.

The system therefore prioritizes the Symbol over supporting logo constructions.

The core principle is:

> **The Symbol is the identity.**

---

# 2. Master Logo

## 2.1 Primary Master Logo

The primary Mehkam logo is the official Symbol.

The Symbol must be treated as the authoritative source from which all derivative logo assets are produced.

The Master Symbol must not be recreated, redrawn, manually traced, or structurally modified.

All derivative assets must originate from the approved Master Logo source file.

---

# 3. Logo Architecture

The Mehkam Logo System consists of:

```text id="m7k9x2"
Master Symbol
    │
    ├── Black Variant
    ├── White Variant
    │
    └── Responsive Variants
          ├── Standard
          └── Simplified
```

The system is intentionally limited.

No unnecessary logo variants should be introduced.

---

# 4. Symbol as Primary Identity

The Symbol may be used independently across:

- Corporate materials
- Websites
- Applications
- Product interfaces
- Social media
- Presentations
- Documents
- Favicon
- App icons
- Avatars
- Physical brand assets
- Marketing materials

When sufficient space exists, the standard approved Symbol should be used.

---

# 5. Monochrome Variants

The official Mehkam Symbol has two primary color variants:

## 5.1 Black Symbol

The Black Symbol is intended for:

- Light backgrounds
- White surfaces
- Neutral light surfaces
- Print applications where dark logo reproduction is required

The preferred dark logo tone should follow the official Mehkam Color System.

---

## 5.2 White Symbol

The White Symbol is intended for:

- Black backgrounds
- Dark surfaces
- Photography with sufficient dark contrast
- Reverse applications
- Dark corporate materials

The White Symbol must maintain sufficient contrast against its background.

---

# 6. Color Restrictions

The Mehkam Symbol is strictly monochromatic.

Official logo colors are limited to:

- Black
- White

The Symbol must not be rendered using:

- Supporting colors
- Semantic colors
- Gradients
- Multi-color treatments
- Decorative color effects

unless a formally approved future Brand Governance decision establishes an exception.

---

# 7. Responsive Logo System

The Mehkam Logo System uses responsive behavior based on available display space.

The objective is to preserve recognition and visual integrity at every scale.

Responsive adaptation must prioritize the Symbol.

---

# 8. Standard Variant

The Standard Variant is used when sufficient display space exists.

It preserves the complete approved Symbol without modification.

Typical applications include:

- Website headers
- Desktop interfaces
- Presentations
- Corporate documents
- Marketing layouts
- Large-format materials

---

# 9. Simplified Variant

When available space becomes constrained, secondary details may be removed while preserving the Symbol's recognizable core.

The Symbol itself must remain identifiable.

The Simplified Variant may be used for:

- Small digital placements
- Compact navigation
- Mobile interfaces
- Small social avatars
- Application icons
- Favicon environments

Simplification must never alter the fundamental identity of the Symbol.

---

# 10. Responsive Principle

The primary responsive rule is:

> **Always preserve the Symbol; remove secondary detail before reducing identity.**

The system should prioritize:

```text id="7b5q8p"
Brand Recognition
       ↓
Symbol Integrity
       ↓
Legibility
       ↓
Detail
```

When space is insufficient, detail is sacrificed before the Symbol itself.

---

# 11. Clear Space

Clear space establishes the minimum protected area surrounding the Symbol.

No:

- Typography
- Graphic elements
- Borders
- Decorative elements
- Photography subjects
- UI components

should visually interfere with the protected area.

The clear-space rule must be applied consistently across all official applications.

---

# 12. Clear-Space Principle

The clear-space system should use a simple repeatable measurement derived from the approved Symbol geometry.

The measurement unit should be defined from a consistent internal feature of the Symbol.

Conceptually:

```text id="k7f2a1"
┌───────────────────────────┐
│                           │
│      Clear Space          │
│                           │
│      ┌───────────┐        │
│      │  SYMBOL   │        │
│      └───────────┘        │
│                           │
│      Clear Space          │
│                           │
└───────────────────────────┘
```

The exact geometric measurement must be established from the final approved Master Symbol artwork.

---

# 13. Minimum Size

The Symbol must remain recognizable and legible at all supported sizes.

Minimum size must be determined according to:

- Symbol geometry
- Production method
- Screen resolution
- Viewing distance
- Application context

A single universal physical size should not be assumed across all media.

---

## 13.1 Digital Minimum Size

Digital minimum size must be established according to:

- Screen rendering
- Pixel density
- Favicon limitations
- Avatar dimensions
- Interface context

The Symbol must remain visually recognizable at the smallest supported implementation.

---

## 13.2 Print Minimum Size

Print minimum size must consider:

- Printing technology
- Reproduction quality
- Paper stock
- Viewing distance
- Production method

Small-format print applications require production validation before approval.

---

# 14. Logo Placement

Logo placement should remain structured and predictable.

Preferred placements include:

- Top-left
- Top-center where composition requires
- Bottom-left
- Bottom-right
- Centered for dedicated brand compositions

Placement must be determined by the composition rather than arbitrary positioning.

The logo must never appear visually trapped against surrounding elements.

---

# 15. Logo and Background

The Symbol must always maintain sufficient contrast against its background.

### Preferred combinations

| Background  | Logo                             |
| ----------- | -------------------------------- |
| Light       | Black                            |
| White       | Black                            |
| Dark        | White                            |
| Black       | White                            |
| Photography | Black or White based on contrast |

When photography is used, the Symbol must be placed in an area that preserves immediate recognition.

---

# 16. Logo on Photography

The Symbol may appear over photography when:

- Contrast is sufficient
- The image does not visually interfere with the Symbol
- Clear space is maintained
- The placement remains controlled

The logo must not be placed over visually chaotic or high-detail areas where recognition is compromised.

---

# 17. Prohibited Logo Treatments

The following treatments are prohibited:

- Changing Symbol geometry
- Stretching
- Compressing
- Rotating
- Skewing
- Distorting
- Adding gradients
- Adding shadows
- Adding Glow
- Adding 3D effects
- Applying unnecessary outlines
- Applying arbitrary colors
- Using semantic colors
- Combining multiple colors
- Reconstructing the Symbol manually
- Adding decorative elements to the Symbol
- Placing typography directly against the Symbol without approved lockup rules

---

# 18. Logo Integrity

The Symbol must always preserve its original:

- Geometry
- Proportion
- Orientation
- Internal relationships
- Visual weight
- Construction

Any modification to the Master Symbol constitutes a change to the Brand Identity and requires formal approval.

---

# 19. Derivative Asset Production

All derivative logo assets must originate from the approved Master Symbol.

Examples include:

- SVG
- PNG
- PDF
- Favicon
- Social Avatar
- Application Icon
- Presentation Logo
- Document Logo
- Marketing Logo

Derivative assets must not become independent sources of truth.

The Master Symbol remains authoritative.

---

# 20. File Format Principles

The Master Logo should be maintained in vector format.

Preferred master format:

```text
SVG
```

Additional production formats may include:

```text
PDF
PNG
```

Raster formats should be generated from the approved vector master rather than recreated independently.

---

# 21. Logo Naming

Logo assets must follow the centralized Asset Naming Standard.

Recommended structure:

```text
MEHKAM-BRAND-ASSET-LOGO-[VARIANT]-[COLOR]-[FORMAT]
```

Examples:

```text
MEHKAM-BRAND-ASSET-LOGO-MASTER-BLACK-SVG
MEHKAM-BRAND-ASSET-LOGO-MASTER-WHITE-SVG
MEHKAM-BRAND-ASSET-LOGO-SIMPLIFIED-BLACK-SVG
MEHKAM-BRAND-ASSET-LOGO-SIMPLIFIED-WHITE-SVG
```

The naming system must remain aligned with the official Asset Governance rules.

---

# 22. Logo Versioning

The Master Logo is version-controlled.

Any change to the approved Symbol must result in a new controlled version.

Example:

```text
v1.0.0
v1.1.0
v2.0.0
```

Minor technical exports must not create unnecessary brand versions.

A version change should represent a meaningful change to the approved logo system.

---

# 23. Logo Governance

The Master Logo System is governed centrally by Mehkam Holding.

No product, department, campaign, designer, or external partner may independently:

- Modify the Symbol
- Create new official variants
- Change official logo colors
- Redraw the Symbol
- Alter proportions
- Define alternative clear-space rules

without Brand Governance approval.

---

# 24. Core Logo Rules

The following rules are mandatory:

1. **The Symbol is the primary Mehkam identity.**
2. **The Symbol is derived from the combination of Persian forms م and ه.**
3. **Official logo colors are limited to Black and White.**
4. **Responsive behavior must preserve the Symbol.**
5. **Secondary details may be removed when space is constrained.**
6. **The Master Symbol is the single source of truth.**
7. **Clear space must always be maintained.**
8. **Minimum size must preserve recognition and legibility.**
9. **Logo geometry and proportions must never be altered.**
10. **All derivative assets must originate from the approved Master Logo.**

---

# 25. Final Logo Principle

The Mehkam Logo System follows one fundamental principle:

> **Reduce complexity before reducing identity.**

The Symbol must remain recognizable, controlled, and consistent regardless of application.

The system therefore favors:

**Recognition over decoration.**

**Consistency over variation.**

**Structure over improvisation.**

**Identity over detail.**
