# Master Color System

---

<div align="center">
  <img src="../../assets/logo/mehkam-symbol.svg" alt="Mehkam Logo" width="150" />
</div>

## Overview

This document defines the authoritative color system of Mehkam Holding.

It establishes the official color architecture, color roles, tonal hierarchy, supporting colors, semantic colors, technical color values, and usage rules across Mehkam's visual ecosystem.

The system is designed around a controlled monochromatic foundation that communicates:

- Authority
- Luxury
- Restraint
- Depth
- Precision
- Stability
- Longevity

The Mehkam color system must remain visually controlled across digital, print, product, marketing, communication, and corporate assets.

---

# 1. Color Philosophy

The Mehkam color system is fundamentally:

> **Monochromatic, restrained, structured, and premium.**

The primary brand expression is built exclusively around Black and White.

Intermediate neutral tones provide the required hierarchy and surface differentiation without introducing unnecessary color complexity.

Supporting colors exist only as controlled accents.

Semantic colors exist to communicate functional states, particularly within user interfaces.

---

# 2. Color Architecture

The Mehkam Color System consists of four primary layers:

| Layer             | Role                                            |
| ----------------- | ----------------------------------------------- |
| Primary Colors    | Core brand expression                           |
| Neutral Scale     | Hierarchy, surfaces, backgrounds, borders, text |
| Supporting Colors | Controlled emphasis and highlights              |
| Semantic Colors   | Functional UI states                            |

The hierarchy is intentional:

```text
Primary
   ↓
Neutral Scale
   ↓
Supporting
   ↓
Semantic
```

Primary and Neutral colors define the brand.

Supporting colors provide controlled emphasis.

Semantic colors communicate functional meaning and should not redefine the brand palette.

---

# 3. Primary Colors

## 3.1 Primary Black

**Name:** Mehkam Black  
**Role:** Primary brand dark  
**HEX:** `#0A0A0A`  
**RGB:** `10, 10, 10`  
**CMYK:** `0, 0, 0, 96`

Mehkam Black is the primary expression of:

- Authority
- Depth
- Formality
- Luxury
- Structural strength

It should be used extensively across:

- Logos
- Headers
- Primary backgrounds
- Corporate materials
- Typography
- Digital interfaces
- Presentation assets

Pure `#000000` may be used where technically required, but Mehkam Black is the preferred brand tone.

---

## 3.2 Primary White

**Name:** Mehkam White  
**Role:** Primary brand light  
**HEX:** `#F7F7F5`  
**RGB:** `247, 247, 245`  
**CMYK:** `0, 0, 1, 3`

Mehkam White provides the primary light counterpart to Mehkam Black.

It should be used for:

- Light backgrounds
- Negative space
- Typography on dark surfaces
- Corporate layouts
- Presentation backgrounds
- Digital surfaces

The slightly neutral character prevents the system from appearing excessively stark while preserving the monochromatic identity.

---

# 4. Neutral Scale

The Neutral Scale provides the structural middle range between Mehkam Black and Mehkam White.

It is used to establish:

- Surface hierarchy
- Text hierarchy
- Borders
- Dividers
- Background levels
- Component states
- Depth
- Visual density

# 5. Supporting Colors

## 5.1 Purpose

Supporting colors exist only for:

- Emphasis
- Highlighting
- Controlled visual distinction
- Limited campaign differentiation

They must never replace Black and White as the primary brand expression.

---

## 5.2 Supporting Color Principles

Supporting colors must be:

- Limited
- Dark
- Restrained
- Sophisticated
- Compatible with the monochromatic foundation

Bright, highly saturated, cheerful, or visually aggressive supporting colors are prohibited.

---

## 5.3 Supporting Palette

The supporting palette should remain intentionally small.

# 6. Semantic Colors

Semantic colors are functional colors rather than primary brand colors.

They are primarily intended for digital products and interfaces.

They communicate:

- Success
- Error
- Warning
- Information

Semantic colors must be distinguishable from one another and must not be confused with the primary brand palette.

# 7. Color Usage Hierarchy

The general priority of color usage is:

```text
1. Primary Black / White
2. Neutral Scale
3. Supporting Colors
4. Semantic Colors
```

The system must never reverse this hierarchy.

Supporting colors must not dominate a composition intended to represent the core Mehkam identity.

Semantic colors must only be used when their semantic meaning is required.

---

# 8. Digital Usage

The digital color system should prioritize:

- Accessibility
- Contrast
- Hierarchy
- Surface separation
- Consistency
- State communication

Black and White should establish the primary visual character.

Neutral tones should establish interface depth.

Supporting colors should remain limited.

Semantic colors should communicate system states.

---

# 9. Product UI Usage

Within product interfaces:

### Primary

Used for:

- Primary text
- Primary backgrounds
- Navigation
- Brand surfaces
- Major actions where appropriate

### Neutral

Used for:

- Secondary text
- Borders
- Dividers
- Surfaces
- Disabled states
- Component hierarchy

### Supporting

Used selectively for:

- Highlighting
- Premium features
- Controlled visual emphasis

### Semantic

Used exclusively according to functional meaning.

Semantic colors must not be used merely as decoration.

---

# 10. Print Usage

For print production, CMYK values should be used as the baseline technical representation.

Print production may require controlled adjustment based on:

- Printing process
- Paper stock
- Ink characteristics
- Color profile
- Production method

Any production adjustment must preserve the intended visual relationship between the colors.

Critical brand assets should be proofed before mass production.

---

# 11. Color Consistency

The same semantic role should maintain the same visual meaning across all Mehkam Touchpoints.

For example:

- A primary dark tone must not change arbitrarily between platforms.
- Success must not become a different color in different products without governance approval.
- Supporting colors must not expand independently within individual campaigns.

Color consistency is a Brand Governance requirement.

---

# 12. Monochromatic Constraint

The Mehkam visual identity is fundamentally monochromatic.

Therefore:

- Black and White remain dominant.
- Neutral tones provide depth.
- Supporting colors remain limited.
- Semantic colors remain functional.
- New colors must not be introduced casually.

Any new persistent brand color requires formal Brand Governance approval.

---

# 13. Prohibited Color Usage

The following are prohibited:

- Highly saturated colors
- Bright cheerful palettes
- Neon colors
- Excessive accent colors
- Rainbow palettes
- Uncontrolled gradients
- Decorative color combinations
- Multiple competing accent colors
- Colors that weaken the monochromatic identity
- Random color selection per Touchpoint
- Using semantic colors as decorative brand colors

---

# 14. Color Accessibility

Color must not be the only mechanism used to communicate important information in digital interfaces.

Semantic states should also use appropriate:

- Icons
- Labels
- Typography
- Status indicators
- Structural cues

This ensures that the system remains understandable regardless of color perception differences.

Contrast requirements must be evaluated according to the target platform and applicable accessibility standards.

---

# 15. Color Naming Convention

All official colors must use standardized names.

Color names should communicate:

- Brand relationship
- Functional role
- Tonal position

Examples:

```text
Mehkam Black
Mehkam White
Obsidian
Graphite
Charcoal
Slate
Neutral Gray
Mehkam Bronze
Mehkam Deep Taupe
Semantic Success
Semantic Error
Semantic Warning
Semantic Information
```

Arbitrary names such as:

```text
Nice Black
Cool Gray
Dark One
Gold-ish
Blue 2
```

must not be used as official system names.

---

# 17. Governance

This document is the authoritative source for Mehkam's Master Color System.

Any change to:

- Primary colors
- Neutral scale
- Supporting colors
- Semantic colors
- Official color values
- Color naming

must follow Mehkam Brand Governance.

No individual product, campaign, team, or designer may redefine the Master Color System independently.

---

# 18. Core Color Rules

The following rules are mandatory:

1. **Black and White are the primary Mehkam colors.**
2. **The primary brand expression must remain monochromatic.**
3. **Neutral tones provide structural hierarchy.**
4. **Supporting colors must remain limited and dark.**
5. **Supporting colors exist for emphasis, not primary expression.**
6. **Semantic colors exist for functional UI states.**
7. **HEX, RGB, and CMYK values must be maintained for official colors.**
8. **Official color names must follow the centralized naming standard.**
9. **New persistent colors require Brand Governance approval.**
10. **Color must never compromise Mehkam's luxury, restraint, or authority.**

---

# 19. Final Color Principle

The Mehkam Color System follows one fundamental principle:

> **Color should create authority through restraint, not attention through excess.**

The system intentionally limits chromatic complexity so that composition, typography, imagery, architecture, and content can carry the visual identity.

Black establishes authority.

White establishes clarity.

Neutral tones establish depth.

Supporting colors establish controlled distinction.

Semantic colors establish functional meaning.

Together, they form a single coherent and scalable color language for Mehkam Holding.

> **Luxury through restraint.**
